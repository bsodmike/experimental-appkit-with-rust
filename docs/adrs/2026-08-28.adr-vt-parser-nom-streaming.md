# ADR: VT/ANSI parser with nom, pure streaming

- Date: 2026-08-28
- Status: Accepted
- Scope: `terminal-core` `parsers::vt` (reachable as `prelude::parsers::vt`)

## Context

The engine needs a parser turning PTY bytes into terminal actions. Per PRD §9 it
must be stateful across reads (a chunk can end mid-sequence or mid-UTF-8). The
conventional Rust choice is the DEC/Williams byte state machine (e.g. the `vte`
crate); the unconventional part of this decision is using **nom**.

## Decision

- **nom, pure streaming.** A stateful `VtParser` buffers unconsumed bytes; each
  `feed` runs a top-level parser over the buffer using nom's streaming
  combinators, so an incomplete sequence yields `Err::Incomplete` and is retained
  until the next feed. Chosen over a framer+nom hybrid (a byte framer feeding nom
  only complete sequences), and over the `vte` state machine.
- **Parser produces typed `Command`s; a separate applier maps them onto
  `Screen`.** The parser depends on nothing but `Color`, so it is testable purely
  as bytes -> commands. `Screen::apply` / `Screen::advance` are the bridge and own
  the new cursor/erase editing ops.
- **Reachable as `prelude::parsers::vt`** via item re-exports (a private module
  cannot be re-exported; see the 2026-08-28 facade ADR).
- **Fully tested with `rstest`** (dev-dependency): per-command tables plus
  streaming-split, multibyte-split and resync cases.

## Consequences

- Correctness details nom forces us to handle explicitly: printable runs emit in
  complete mode (text shows as it arrives) but keep a trailing partial UTF-8
  sequence buffered; the feed loop resyncs past malformed bytes and guards against
  zero-width success.
- Unhandled ESC/OSC sequences are framed and consumed (`Command::Ignored`,
  filtered from output) so the stream never stalls on what is not yet acted on.
- Pure-streaming re-scans the buffer per feed; acceptable at PTY chunk sizes, and
  the buffer is compacted each feed.

## Coverage and deferrals

Implemented: printable UTF-8, C0 (BEL/BS/HT/LF/CR), CSI cursor moves
(CUU/CUD/CUF/CUB, CUP/HVP), erase (ED/EL), SGR (attributes, 16/256/RGB colour).
Deferred to later slices: scroll regions, DSR/DA replies, DEC private modes
(DECCKM etc.), DCS, mouse reporting, and full OSC (title) handling.

*Update 2026-08-28:* all but DCS and mouse reporting landed in the next slice;
see `2026-08-28.adr-vt-coverage-and-alternate-screen.md` for what is covered now
and what is still deferred.
